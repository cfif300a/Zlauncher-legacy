# ZLauncher
Наш дискорд сервер: https://discord.gg/2E3sTrFhb2

Десктопный клиент для управления версиями, модификациями и запуском Minecraft с поддержкой офлайн-авторизации, изолированных профилей и интеграции с каталогом Modrinth.

![Интерфейс ZLauncher](screenshot1.png)

Приложение разработано на базе Electron React, TypeScript и Tailwind CSS. Архитектура ориентирована на модульность и изоляцию сборок: каждый профиль использует собственную директорию для модификаций, сохранений и настроек, разделяя при этом общие библиотеки и ассеты игры для экономии дискового пространства.

## Основные возможности

### Изолированные профили (инстансы)
- Создание независимых сборок с выбором версии игры, загрузчика и графической иконки.
- Изоляция файловой системы: моды, ресурспаки, шейдеры и файлы сохранений хранятся раздельно в папках профилей (`instances/<id>/`).
- Автоматическая синхронизация инстансов с диском при старте приложения, исключающая потерю конфигурации при перезапуске или сбросе настроек.

### Поддержка загрузчиков модификаций
- Совместимость с Fabric, Forge, NeoForge, Quilt и оригинальной версией (Vanilla).
- Автоматическая загрузка профилей и генерация конфигураций для Fabric и Quilt.
- Сравнительные метрики производительности и ресурсоемкости загрузчиков в интерфейсе.
- Полное исключение снапшотов из списков выбора — доступны только стабильные релизы.

### Интеграция с Modrinth
- Встроенный каталог для поиска и загрузки модов, шейдеров и текстур через Modrinth API.
- Строгая фильтрация версий: скачиваемые файлы автоматически сверяются с версией Minecraft и загрузчиком активного профиля.
- Управление установленными модификациями: включение, отключение, удаление и подсчет объема файлов.

### Офлайн-авторизация и сохранение данных
- Генерация детерминированного UUID по стандарту RFC 4122 v3 (MD5 на основе имени игрока). Это обеспечивает сохранность инвентаря, сундуков, статистики и одиночных миров между сессиями.
- Поддержка скинов и плащей: интерактивный 3D-просмотр (Three.js), загрузка локальных файлов, интеграция со скинами Ely.by и сервисами Mojang.

### Настройки и мониторинг
- Графический селектор оперативной памяти с анализом свободной памяти системы и цветовой индикацией безопасных порогов.
- Автоматическое обнаружение установленных версий Java в системе (Java 8, 17, 21) с возможностью ручного выбора исполняемого файла.
- Пресеты оптимизации JVM-аргументов (включая флаги сборщика мусора Aikar G1GC) и поле для пользовательских параметров запуска.
- Встроенная консоль процесса: вывод логов Minecraft и JVM в реальном времени, фильтрация по уровням важности (Error, Warn, Info, System), поиск по тексту и экспорт лога в текстовый файл.
- Встроенная галерея скриншотов с масштабированием, навигацией, открытием в проводнике и прямым копированием изображения в буфер обмена.

## Стек технологий

- Платформа: Electron 35
- Интерфейс: React 19, TypeScript, Tailwind CSS
- Сборщик фронтенда: Vite 6
- 3D-графика: Three.js, Skinview3D
- Сборщик дистрибутивов: electron-builder

## Требования к окружению

- Операционная система: Windows 10 / 11 (64-bit)
- Node.js: версия 18.0 или выше
- Java Runtime Environment:
  - Java 21+ для версий Minecraft 1.20.5 и новее
  - Java 17 для версий 1.18 - 1.20.4
  - Java 8 для версий 1.12.2 и старее

## Установка и запуск из исходников

1. Клонирование репозитория:
```bash
git clone https://github.com/cfif300a/Zlauncher.git
cd Zlauncher
```

2. Установка зависимостей:
```bash
npm install
```

3. Запуск приложения:
```bash
npm start
```

4. Сборка фронтенда и Electron-кода:
```bash
npm run electron:build
```

## Сборка исполняемого файла (EXE)

Для создания портативного EXE-файла выполните:
```bash
npm run dist:portable
```
Готовый исполняемый файл будет сгенерирован в директории `release/` (например, `ZLauncher 1.0.0.exe`).

Для автоматизации рутинных действий в корне проекта предусмотрены командные файлы:
- `start.bat` — запуск лаунчера.
- `build.bat` — компиляция TypeScript и Vite.
- `build_exe.bat` — сборка автономного EXE-файла с использованием зеркал зависимостей.

## Структура проекта

- `electron/` — главный процесс Electron, модуль запуска игры, многопоточный загрузчик и обработчики IPC.
- `src/` — пользовательский интерфейс на React: экраны, компоненты, аудио-движок и стили.
- `dist/` — скомпилированный фронтенд.
- `dist-electron/` — скомпилированный код Electron.
- `release/` — выходная директория готовых исполняемых файлов.
